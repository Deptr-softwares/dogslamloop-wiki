Community Ranking

The Free Submit tier list. Closing voting hides the ballot and refuses new ratings — the published ranking stays readable, because deleting the community's answer is a much bigger act than pausing new ones.

Below this a character is shown as unplaced rather than ranked, so three people's opinion is never presented as the community's.

Only changes anything for a character whose votes divide exactly in half — everyone else is decided by the middle vote either way. The lower tier is the cautious answer: a character only moves up if more than half the voters put them there.

Reset the ranking. Deletes every vote so the community ranking rebuilds against a new game patch. The tier scale and these settings are kept. This cannot be undone.

Delete an Account

Removes the account and its email address. Their past edits stay on the wiki, re-attributed to "Deleted user", so page history doesn't break. This can't be undone.

Media Garbage Collection

Finds files in the media library that no page links to any more. Scanning changes nothing - deleting is a second, separate step, and it lists what it found first.
