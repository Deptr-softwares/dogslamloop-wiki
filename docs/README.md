# Notes on the code

How Dogslamloop Wiki's code is built, for the owner and anyone reading the code. Text readers see lives in the pages, not here.

- `glossary.md`: what each thing is called on screen, in the code and in the data, and the renames planned.
- `area-template.md`: the shape of an area page.
- One page per area of the site (the editor, the character page, tier lists and so on), each with its files, its data, what to watch for, and a Decisions list. The history that sat in the comments in `js/` and `style/` is in these pages now; the Node scripts and the Discord relay keep theirs until they are trimmed.

The rules for writing code are in `CLAUDE.md` (the index) and `.claude/rules/`.

robots.txt asks search engines to skip this folder. Nothing secret goes here.
