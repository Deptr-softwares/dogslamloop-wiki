## Candidates, all carried from v0.19's known-open

**Engineering, mine to do once chosen:**

* **The stylesheet-order hazard.** A character stub loads `Layout.css` last; a
  system stub loads it second, before `Buttons.css`. Between those two files,
  which rule wins depends on the page type, so every equal-specificity pair
  across them is a latent v0.19-B1 on 18 pages. Fixed for one class only.
  Reordering the system template settles it everywhere in one line — and
  silently re-decides every other shared class, so it wants a deliberate pass.
* **The suite is close to its limit.** ~1,808 tests against a single
  `python -m http.server` with 4 workers, ~18 minutes. The failure shape is a
  burst of flakes across unrelated page-loading specs with the run time up by a
  quarter. The real fix is a threaded server or parallel-safe fixtures.

  identically by v0.18, the third by v0.19. Unifying contradicts a stated
  `CLAUDE.md` convention, so it is the owner's call.

## Carried warnings

**A release conflicts on stubs, and the fix is to regenerate.** v0.19's release
PR is *not* evidence against this — it merged clean only because `main` had
taken no `chore: regenerate` commit since v0.18, so there was nothing on the
other side to conflict with. The next release that follows a regeneration on
`main` will conflict on every stamped stub, exactly as v0.18's did on 62 files.
Resolve toward the integration branch, run `npm run generate`, then check that
nothing only `main` had was reverted.

**`data/search-index.json` and `data/search-fulltext.json` are now in that
surface too.** They regenerate per branch from Supabase like every other
artifact. Regenerate, never hand-merge.

**"Regenerate, never hand-merge" has a blind spot**, and v0.19 found it: it
recovers anything a generator owns and **silently discards anything in the same
files that it does not.** Taking the integration branch's side on 64 stamped
HTML files dropped a hand-added script tag from 17 pages, with the suite green
and no error anywhere — the searchbar simply would not have existed. Derived
tests now pin it; the general shape does not have a general fix.
