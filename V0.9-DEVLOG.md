## Scope: the Owner Page becomes a real CMS

Split out of v0.8 on 2026-08-07 when the "finish owner.html" ask grew large enough to be its own version. Today `owner.html` has exactly two tools: a blind single-email role lookup, and media garbage collection.

The goal, in the owner's own words: **a page where the site can be edited without touching code or raw data.**

1. **Personnel roster** — a real list of everyone holding a role, not a blind email lookup.
2. **Page permissions manager** — `page_permissions` is a real table (`20260731000000_page_permissions.sql`) with a public-read policy, but it was only ever seeded by a migration `INSERT`. No write policy, no UI.
3. **Site content management** — create/delete character and system pages directly, instead of page creation only happening implicitly through the editor.
4. **Site text + meta tag editing** for the three hub pages: `index.html` ("Main Dashboard"), `systems/index.html` ("Side Dashboard"), `characters/index.html` ("Character Dashboard"). Note: the site has **zero** SEO/OG meta tags today.
5. **Credits + collaborators editing**, including reconciling `index.html`'s hardcoded Credits block against the `systems/collaborators` page — currently two sources of truth. Re-verify the old claim that `collaborators` is `editRole: locked` and bypasses the CMS before planning around it.
6. **FAQ editing** — `data/faq.json` is a static file today, so edits need a commit.
7. **Quick update / hotfix posts** — short-form site news that doesn't warrant a full version entry in `data/updates.json`. Worth deciding at design time whether this shares infrastructure with the blog (item 8) or is genuinely separate.
8. **Blog system** — a new content type, authored from owner.html, with a page to read posts.
9. **Account/data deletion tooling** — added to scope 2026-08-07. Deleting a user currently means removing them from Supabase's auth table by hand. `privacy-policy.html` (shipped in v0.8) says deletion is handled manually on Discord request and warns there's no self-serve button *yet* — **when this ships, update that page's "Deleting your data" section to match.**

**Before starting**: this is roughly v0.6-sized. Plan it properly (Plan mode) and confirm scope is still current first — the same check-in that turned v0.8's "finish owner.html" line item into this entire version.
